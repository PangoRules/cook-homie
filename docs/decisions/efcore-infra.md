# EF Core Infrastructure Decision

**Date:** 2026-04-26
**Status:** Implemented

## Decisions Made

- **Model scope:** Full v1 data model (InventoryItem, Recipe, RecipeIngredient, ShoppingItem) as per `docs/02-DataModel.md`.
- **Migration approach:** Single `InitialCreate` covering tables, primary keys, foreign keys, required/nullable constraints. No extra indexes or check constraints at this stage.
- **Test strategy:** `CookHomie.Infrastructure.Tests` uses integration-style tests against a real EF Core provider (no DbContext mocking).
- **Repository pattern:** Thin repository implementing `IInventoryRepository`; persistence logic in infra layer, business logic in application layer.

## Architecture & Boundaries

### Domain Layer
- `InventoryItem`, `Recipe`, `RecipeIngredient`, `ShoppingItem` fully defined with v1 fields.
- All IDs are `Guid` (UUID).
- `Recipe.Tags` is `string[]` for PostgreSQL `text[]` mapping.
- `RecipeIngredient.IngredientName` stays text (no FK) — preserves fuzzy-match design.
- `ShoppingItem.LinkedRecipeId` is a nullable FK to Recipe.
- `CreatedAt` / `UpdatedAt` timestamps on entities that require audit tracking.

### Infrastructure Layer
- **AppDbContext:** EF Core DbContext with `DbSet<>` for all four entities. Minimal fluent configuration for table names, keys, nullability, and array mapping.
- **InventoryRepository:** Implements `IInventoryRepository`; persists via EF + `SaveChangesAsync`.
- **Migrations:** Single `InitialCreate` generated by `dotnet ef migrations add`.

### Application & WebApi
- Application use case calls `IInventoryRepository.AddAsync` — unchanged by this layer.
- WebApi DI wiring registers `AppDbContext` and the `IInventoryRepository` implementation.
- Connection string read from configuration at startup; fails fast if missing.

## Success Definition

- All four v1 entities exist in domain with correct field shapes.
- `InitialCreate` migration applies cleanly to an empty PostgreSQL database.
- `InventoryRepository` passes persistence and FK integrity tests.
- `dotnet build src/CookHomie.Api/CookHomie.sln` and `dotnet test` pass clean.
